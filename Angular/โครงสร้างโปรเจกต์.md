#angular-outline/file-structure 

#file-structure/structure

```
my-angular-app/  
├── src/  
│ ├── app/ # โฟลเดอร์หลักของแอป (Component, Module อยู่ที่นี่)  
│ ├── assets/ # เก็บไฟล์รูปภาพ, ไฟล์ static อื่น ๆ  
│ ├── environments/ # เก็บ config สำหรับ dev/prod  
│ ├── index.html # HTML หลักของแอป  
│ ├── main.ts # จุดเริ่มต้นของแอป (Bootstrap Angular)  
│ └── styles.css # Styles หลักของแอป  
├── angular.json # ตั้งค่าโปรเจกต์ Angular (build, assets, styles ฯลฯ)  
├── package.json # จัดการ dependencies ของโปรเจกต์
```

---

## 🔍 ทำความเข้าใจองค์ประกอบหลักของ Angular

### 📦 Module (`NgModule`)
- กลุ่มของ component, directive, pipe ที่ทำงานร่วมกัน
- ไฟล์หลักคือ `app.module.ts`

```ts
@NgModule({
  declarations: [...],
  imports: [...],
  bootstrap: [AppComponent]
})
export class AppModule {}
```

### 🧩 Component

#### หน่วยย่อยของ UI ประกอบด้วย 4 ส่วนหลัก
- **Template (HTML)** — ส่วนแสดงผล
	
- **Styles (CSS)** — การตกแต่ง
	
- **Class (TypeScript)** — จัดการ logic
	
- **Metadata (Decorator)** — บอก Angular ว่านี่คือ component
