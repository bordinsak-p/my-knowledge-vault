# 🌱 Greenhouse

ที่เพาะไอเดียโปรเจกต์ที่อยากทำ — ตั้งแต่ยังเป็นความคิดลอย ๆ จนถึงลงมือทำจริง
บางอันรอด บางอันไม่รอด **การทิ้งไอเดียคือผลลัพธ์ที่ถูกต้อง ไม่ใช่ความล้มเหลว**

---

## วิธีใช้

1. ไอเดียใหม่โยนเข้า [[Ideas Inbox]] ก่อน บรรทัดเดียวพอ ไม่ต้องคิดเยอะ
2. อันไหนยังคิดถึงอยู่หลังผ่านไปสักพัก ค่อยยกร่างเป็นโน้ตเต็มจาก [[Research Project]]
3. โน้ตเต็มไปอยู่ใน `Greenhouse/Projects/`
4. อัปเดต `status` ใน frontmatter เวลาสถานะเปลี่ยน แล้วย้ายชื่อในตารางข้างล่าง

---

## Status ที่ใช้

| status | แปลว่า |
|---|---|
| `seed` | เป็นแค่ไอเดีย ยังไม่ได้ตรวจสอบอะไรเลย |
| `sprouting` | กำลังหาข้อมูล / อ่าน prior art / ลองของเล่นเล็ก ๆ |
| `growing` | ลงมือสร้างจริงแล้ว |
| `harvested` | เสร็จ หรือได้คำตอบที่ต้องการแล้ว |
| `composted` | เลิกทำ — **ต้องเขียนไว้ด้วยว่าทำไม** ตรงนี้คือของมีค่า |

## คำถามที่ควรตอบได้ก่อนขยับจาก `seed`

- ปัญหานี้เป็นปัญหาของใคร — ของเราเองหรือของคนอื่น?
- ถ้าไม่ทำ จะเกิดอะไรขึ้น? (ถ้าตอบว่า "ไม่เกิดอะไร" ก็ปล่อยมันไว้ตรงนั้น)
- มีคนทำไปแล้วหรือยัง? ถ้ามี ทำไมของเขาถึงยังไม่พอ?
- ตัวเล็กที่สุดที่พิสูจน์ได้ว่าไอเดียนี้เวิร์ก คืออะไร?
