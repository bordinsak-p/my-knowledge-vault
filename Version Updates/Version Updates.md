# 🆕 Version Updates — อะไรใหม่ / อะไรเลิกใช้ ของแต่ละเทคโนโลยี

หน้ารวมโน้ตติดตามอัปเดตเวอร์ชันของแต่ละเทคโนโลยีที่ใช้ในวอลต์นี้ — ต่างจากโน้ตหลักในแต่ละโฟลเดอร์ (`Angular/`, `Quarkus/`, `Java/` ฯลฯ) ที่เน้นอธิบายแนวคิดแบบยั่งยืน **โน้ตในนี้เน้นแค่ "เวอร์ชันล่าสุดมีอะไรใหม่ อะไรถูก deprecate/ถอดออกไปแล้ว"**

> ⚠️ **โน้ตในหมวดนี้ล้าสมัยเร็วกว่าที่อื่นในวอลต์มาก** — เช็กบรรทัด "อัปเดตล่าสุด" ที่หัวแต่ละโน้ตก่อนเชื่อ 100% เสมอ อย่าเอาไปอ้างอิงโดยไม่ดูวันที่
