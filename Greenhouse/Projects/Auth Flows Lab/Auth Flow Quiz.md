# 📝 Auth Flow Quiz — ตอบแล้วให้ Claude รีวิว

แบบทดสอบความเข้าใจของ [[Auth Flow Spec]] ไม่มีเฉลยในไฟล์นี้ ตอบเสร็จแล้วบอก Claude ให้มารีวิว

**วิธีตอบ**
- ตอบ **ก่อน** รันหรืออ่านสเปคซ้ำ ด้วยความเข้าใจตอนนี้ ผิดไม่เป็นไร จุดที่ผิดคือสิ่งที่ต้องรู้
- ถ้าไม่รู้ เขียนว่า "ไม่รู้" ดีกว่าเดา เพราะรีวิวแล้วจะเห็นช่องว่างจริง
- ตอบสั้นได้ 1–3 ประโยค ใช้คำของตัวเอง ไม่ต้องลอกศัพท์
- ช่อง "ผลจริง" ไว้เติมทีหลังเมื่อรันทดลองแล้ว
