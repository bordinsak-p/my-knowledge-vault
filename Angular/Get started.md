# พื้นฐานการเริ่มต้นใช้งาน Angular

#angular-outline/get-started 
## 📌 Angular คืออะไร?

**Angular** คือเฟรมเวิร์กแบบโอเพนซอร์สจาก Google สำหรับพัฒนา **เว็บแอปพลิเคชันฝั่ง Frontend** ด้วยภาษา **TypeScript**  
เหมาะสำหรับสร้างเว็บแอปขนาดกลางถึงใหญ่ เช่น ระบบจัดการข้อมูล เว็บแอปองค์กร ฯลฯ

---

## 🔧 การติดตั้งเครื่องมือที่จำเป็น

### 1. ติดตั้ง Node.js  
Angular ต้องการ Node.js เพื่อจัดการแพ็กเกจต่าง ๆ

ดาวน์โหลดได้ที่: [https://nodejs.org](https://nodejs.org)

> ✅ แนะนำให้ติดตั้งเวอร์ชัน LTS

### 2. ติดตั้ง Angular CLI  
Angular CLI คือเครื่องมือช่วยในการสร้างและจัดการโปรเจกต์ Angular

```bash
npm install -g @angular/cli
```

### สร้างโปรเจกต์ Angular แรก

ใช้คำสั่ง `ng new` เพื่อสร้างโปรเจกต์ใหม่:
```bash
ng new my-angular-app
```

### รันโปรเจกต์ด้วย ng serve

```bash
cd my-angular-app
ng serve
```

เปิดเบราว์เซอร์ไปที่: [http://localhost:4200](http://localhost:4200)
